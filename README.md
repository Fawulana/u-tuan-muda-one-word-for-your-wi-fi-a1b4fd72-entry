One word for a Wi-Fi network name: **Gaslighting** — full signal bars, nothing loads, and the router insists everything is fine.

## Run it

```sh
python3 main.py
```

Writes the single word `Gaslighting` (11 bytes, no trailing newline) to `/output/entry.txt`. Deterministic, offline, stdlib-only — every run is byte-identical.
